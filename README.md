# 🌾 HarvestGuard AI
### Intelligent Agricultural Storage Monitoring and Environmental Management System

**HarvestGuard AI** is an AI-assisted Internet of Things (IoT) system designed to monitor agricultural storage environments, identify potentially harmful environmental conditions, and provide intelligent recommendations to help protect stored agricultural products.

The project combines environmental sensing, embedded systems, intelligent data analysis, and automated environmental control.

---

## 1. The Problem

Poor environmental conditions inside agricultural storage facilities can contribute to moisture accumulation, excessive temperatures, and deterioration of stored agricultural products.

Traditional storage monitoring methods may not provide continuous environmental information or timely warnings.

HarvestGuard AI aims to address these challenges through affordable, intelligent monitoring and environmental management.

## 2. Our Solution

HarvestGuard AI uses an ESP32-based monitoring system to collect environmental data from sensors positioned inside and outside a storage environment.

The system compares environmental conditions, displays readings, identifies potential risks, and supports appropriate environmental management actions.

### Key Features

- Indoor and outdoor temperature monitoring.
- Indoor and outdoor humidity monitoring.
- Environmental condition comparison.
- Real-time monitoring using ESP32.
- LCD-based information display.
- Audible and visual alerts.
- AI-assisted environmental recommendations.
- Automated ventilation and environmental control.
- Dashboard-based system monitoring.

## 3. System Architecture

The system follows this general architecture:

**Environmental Sensors → ESP32 → Data Processing → AI Analysis → Dashboard and Alerts → Environmental Control**

The ESP32 handles sensor acquisition and embedded control, while the AI component supports intelligent interpretation of environmental conditions and recommendations.

## 4. Hardware Components

The prototype uses components including:

- ESP32 development board.
- DHT11 temperature and humidity sensors (indoor and outdoor).
- 16×2 LCD display.
- Resistive soil moisture sensor.
- Relay module.
- 5V ventilation fan.
- Passive buzzer.
- Indicator LEDs.
- Supporting electronic components.

## 5. Software and Technologies

## 6. How It Works

1. Environmental sensors collect temperature and humidity readings.
2. The ESP32 processes the collected sensor information.
3. Indoor and outdoor conditions are compared.
4. The system identifies potentially unsafe environmental conditions.
5. The AI component supports environmental recommendations.
6. Alerts notify users when attention is required.
7. Automated control mechanisms support appropriate ventilation actions.
